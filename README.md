# 🩺 Diabetes Prediction Using Machine Learning

## 📌 Project Overview

This project aims to build a **machine learning model** that predicts whether a person is likely to have diabetes based on medical and demographic features such as glucose level, blood pressure, BMI, age, and insulin levels. Early prediction can help support timely diagnosis and preventive healthcare decisions.

---

## 📊 Dataset

* Source: Kaggle (Diabetes Dataset)
* Type: Tabular medical data
* Target variable: `Outcome`

  * `1` → Diabetic
  * `0` → Non-diabetic

---


## 🧠 Methodology

1. **Data Preprocessing**

   * Handling missing values
   * Feature scaling
   * Outlier handling

2. **Model Training**

   * Trained multiple ML models
   * Selected best model based on validation performance

3. **Evaluation Metrics**

   * Accuracy
   * Precision
   * Recall
   * F1-score
   * ROC-AUC

4. **Prediction**

   * Generated predictions on test data

## 📈 Results

The final model demonstrates strong generalization performance with a balanced trade-off between precision and recall. Model selection was based on cross-validation rather than public leaderboard tuning to avoid overfitting.
